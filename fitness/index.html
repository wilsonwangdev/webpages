疼？先分清 DOMS 还是损伤

特征DOMS（正常酸痛）肌腱 / 关节损伤
达峰24–48 小时持续，无峰谷
消退3–5 天自愈数周不干预不好
感觉酸胀、钝痛刺痛、点状、尖锐
静止时不疼夜间 / 静息也疼
运动时热身后减轻越动越疼

DOMS = Delayed(延迟) Onset(发作) Muscle(肌肉) Soreness(酸痛)
记忆锚：「练完第二天最疼，不是当时最疼」 → 那就是 DOMS。
⚠️ 夜间疼醒 / 抬手不过头顶 / 明显无力 / >2 周无改善 → 就医。

重量怎么选：做完目标次数还剩约 3 次力气 = 对了

进阶：连续 2 次做满目标次数且姿势不变 → 加最小一档

蛋白：目标 134g/天（1.6 g/kg）· 缺口靠鸡蛋 + 蛋白粉补

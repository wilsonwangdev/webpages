workslop

无用功 / 看似成品的工作

AI-generated work that masquerades as good work, but lacks the substance to advance a given task.

AI 生成、伪装成好成果的工作，但缺少推进某一具体任务所需的实质。

opaque recurrence

不透明递归

OpenAI Astra 用的推理技术：可见的推理 token 更少、能力更强，代价是研究人员再也无法通过思维链审计它是怎么得出结论的。这个词 9 月一出，安全研究者集体警觉。

Astra is also possibly OpenAI's most controversial model yet due to its use of a particular reasoning technique known as opaque recurrence. This technique is known to obscure an important model-monitoring process known as chain of thought.

Astra 也可能是 OpenAI 至今最具争议的模型，原因是它使用了一种叫「不透明递归」的推理技术。这项技术会遮蔽一个重要的模型监控过程——思维链。

It reasons with fewer visible tokens, which makes it more capable but means you can't actually audit how it got to an answer anymore.

它用更少的可见 token 推理，这让它更强，但也意味着你再也无法审计它是怎么得到答案的。

harness engineering

外壳工程

设计模型外面那一层运行时：它能调用哪些工具、能读改什么、怎么自检、什么时候停。2026 年被说成「取代 prompt engineering 的技能」——同一个模型换个外壳，结果完全不同。

The bottleneck is everything around the model: who gives it tools, who checks its work, what it remembers, what it is allowed to touch, and whether anyone can see what it did. That layer has a name now. It is called the harness.

瓶颈在于模型周围的一切：谁给它工具、谁检查它的产出、它记得什么、它被允许碰什么、以及有没有人能看到它做了什么。那一层现在有名字了，叫「外壳」。

Designing the runtime around a model… The harness often matters more than which model sits inside it.

围绕模型设计运行时……外壳往往比里面装的是哪个模型更重要。

AI dark factory

AI 黑灯工厂

代码由触发器启动的 agent 编写、不经任何人阅读就上线，唯一的检查是自动化测试和自动化评审。名字借自「黑灯工厂」——车间里没有工人。

A software setup where coding agents are started by triggers rather than people and their code ships without any human reading it; automated tests and automated review are the only checks. Named after lights-out factories that run with no workers on the floor.

一种软件生产形态：编码 agent 由触发器而非人来启动，它们写的代码不经任何人阅读就发布；自动化测试与自动化评审是仅有的检查。名字来自「黑灯工厂」——车间里一个工人都没有。

这是一个实验性项目的开篇——用 Tauri v2 构建一个对标 Codex CLI 和 Hermes Desktop 的 AI Agent 桌面客户端，取名 Wilson Desktop。这篇文章记录最初的选型决策和项目骨架搭建过程。

3|

为什么不是 Electron？

4|

Hermes Desktop 用的是 Electron，打包后 .app 大小 310 MB。Wilson Desktop 用 Tauri，同样功能的骨架打出来 11 MB。差距来自 Electron 内置了完整的 Chromium 渲染引擎，而 Tauri 使用系统的 WebView。

5|

但包体大小不是唯一的决策因素。更重要的是：

6|
    7|
  • Rust 编译器的错误信息对 agent 友好。 在 agent 开发模式下，Rust 精确的编译错误比 JS 的运行时 undefined 错误更容易自动修复。
    • 8|
  • 安全性。 Tauri 的权限模型比 Electron 严格，每个 API 调用需要显式声明。
    • 9|
  • 代价是生态成熟度。 Electron 社区沉淀了十年，Tauri v2 才刚稳定。遇到冷门 bug 可能需要自己排。
    • 10|
11|

最终决策是一个权衡：Wilson Desktop 的目标是探索 Tauri 在复杂桌面应用的工程实践，所以接受生态不成熟的风险。
